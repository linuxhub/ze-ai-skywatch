泽 · 观天镜（Ze AI SkyWatch）Windows x64 便携版
用 AI 看懂进程与网络

适用：Windows 10 / 11，Intel 或 AMD 64 位电脑。

使用：
1. 将 ZIP 完整解压到本地文件夹。
2. 双击「ZeAISkyWatch.exe」。无需安装 Go 或 WebView2。
3. 启用系统托盘后，关闭窗口会继续后台运行；从托盘菜单退出应用。

功能：
- 整机 CPU、内存，进程列表、CPU 排行和进程详情。
- TCP 监听端口，TCP / UDP 连接端点、状态和本地网卡。
- 物理以太网 / Wi-Fi 网卡的整机下载、上传速度与趋势。
- 本地 IP 标注簿、AI 模型服务配置和进程分析。
- 结束进程前确认，核对进程启动时间和所属用户，只处理当前用户可访问的进程。

Windows 版差异：
- 暂不支持逐进程 / 逐连接下载上传速率、流量排行和连接地图。连接表中速率显示「—」。
- UDP 表仅提供本地绑定，无法显示 UDP 对端。
- 停止进程为强制结束，不支持 macOS 的 SIGTERM / SIGKILL 选项。
- 其他用户、系统及受保护进程的信息可能不可读，应用不会自动提权。
- 程序未进行 Windows 代码签名。

设置保存在当前用户的应用数据目录。API 密钥保存在本机 settings.json，未加密。
