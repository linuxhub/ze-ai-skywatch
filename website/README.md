# 泽 · 观天镜产品介绍页

独立、无需构建的静态网站。HTML、CSS、JavaScript 和图片均在本目录内，没有前端依赖、外部字体、统计脚本、AI 请求或后端服务。

## 查看

直接打开 `index.html`，或在此目录运行：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:4173`。

将整个目录原样放到任意静态服务器或静态托管平台即可部署，所有本地资源均使用相对路径，支持子目录访问。

## 文件

- `index.html`：产品介绍、下载链接、常见问题、SEO 元信息。
- `styles.css`：深色主题、桌面与手机适配、键盘焦点和减少动态效果支持。
- `script.js`：预设的 AI 分析示例切换、应用截图标签切换、移动端导航。
- `assets/`：项目图标及应用实际界面测试截图，截图使用示例数据。

## 下载与文案维护

当前下载链接指向 GitHub `v0.4.6` 的 macOS arm64 DMG、Windows x64 ZIP 和校验文件。更新版本时，在 `index.html` 中同步修改版本文字、结构化数据及附件 URL。

首屏为预设内容的交互演示，不调用真实 AI，不读取访问者的进程或网络数据。应用截图也使用示例数据，不能作为实际性能或安全检测结论。

产品能力与平台边界来自项目 README。当前 macOS 附件面向 Apple Silicon，尚未进行 Developer ID 签名与公证；Windows 包未签名，尚未完成 Windows 实机验证；Windows 不支持逐进程／逐连接速率、流量排行与地图。模型服务由用户自行配置，调用费用由对应提供商决定。
